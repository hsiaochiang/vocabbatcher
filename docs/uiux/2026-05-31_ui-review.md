## 逐項驗收（使用者角度）

### 功能 A-2 + B-6：清除全選按鈕

**這個功能是做什麼的：**
在選字頁面加了兩個按鈕：「清除」可以一次取消全部已選的字，「全選篩選結果」可以一次選滿目前篩選後看到的字（最多 25 個）。

**我測試的步驟：**
1. 我打開了「建立新批次」頁面
2. 我先選了 3 個字，看到計數器旁邊出現「清除」按鈕
3. 我點了「清除」→ 所有勾選被取消，計數器回到 0
4. 我點了「全選篩選結果」→ 自動選了 25 個字
5. 我先篩選「高頻 ≥8」（只剩約 257 筆），再點「全選篩選結果」→ 選了 25 筆就停止

**我看到的結果：**
- 清除按鈕：紅色文字，只在有勾選時才出現
- 全選按鈕：藍色文字，選滿 25 後自動變灰色不可點
- 全選不會超過 25 個上限

**測試結論：** ✅ 符合預期

**你自己驗收的方法：**
1. 打開 App → 「建立新批次」
2. 勾選幾個字 → 看到右上角出現「清除」
3. 點「全選篩選結果」→ 計數器變成 25/25
4. 如果以上都正確，代表完成 ✅

### 功能 A-5：篩選選項與實際資料對應

**這個功能是做什麼的：**
詞性篩選的選項改成中文標籤，而且新增了「代名詞」「介系詞」「連接詞」三個選項，完整對應資料中的所有詞性。

**我測試的步驟：**
1. 我打開批次建立器
2. 我看到詞性篩選列：全部詞性、名詞、動詞、形容詞、副詞、代名詞、介系詞、連接詞、其他

**我看到的結果：**
- 點「名詞」→ 只顯示名詞的字（n.）
- 點「代名詞」→ 顯示 he, she, I, we 等代名詞
- 點「介系詞」→ 顯示 in, on, at 等介系詞
- 標籤全部是中文，容易理解

**測試結論：** ✅ 符合預期

**你自己驗收的方法：**
1. 打開批次建立器 → 看詞性篩選列
2. 點「代名詞」→ 確認只顯示代名詞的字
3. 如果看到中文標籤且篩選正確，代表完成 ✅

### 功能 B-2：Hub 卡片辨識度

**這個功能是做什麼的：**
批次 Hub 的四張功能卡片改為不同顏色，讓你一眼就能分辨哪個功能最常用。

**我測試的步驟：**
1. 建好一個批次 → 進入批次 Hub
2. 觀察四張卡片

**我看到的結果：**
- 翻牌學習：藍色底色 + 藍色邊框 + 顯示字數（最突出）
- 錄音播放：橘色圖示 + 淺橘底色
- 練習測驗：綠色圖示 + 淺綠底色
- 學習統計：紫色圖示 + 淺紫底色
- 未推出的三張有「即將推出」標示且稍微透明

**測試結論：** ✅ 符合預期

**你自己驗收的方法：**
1. 建立一個批次 → 進入批次 Hub
2. 如果四張卡片顏色各不同，「翻牌學習」最明顯，代表完成 ✅

1. 進入翻牌學習 → 用手指試按發音按鈕
2. 如果容易按到且不會按到旁邊的東西，代表完成 ✅

## 測試時發現的注意事項

1. **「全選篩選結果」邏輯** — 會加入目前篩選結果中的前 25 筆。如果先選了 10 個再按全選，會再補選 15 個到 25 為止。
2. **詞性篩選新增 3 項** — 代名詞（30 筆）、介系詞（11 筆）、連接詞（8 筆）是原本歸在「其他」的，現在獨立出來方便老師針對特定詞性出題。
3. **「其他」類別** — 現在只剩 aux.（助動詞 7 筆）和 art.（冠詞 3 筆）。
