## 一句話目標
> 國中會考英文單字練習 App（Web/Android 優先）：讓學生從 PDF 詞表勾選最多 25 個單字，批次聽錄音、翻牌學習、四題型練習，追蹤正確率並複習錯題。

## 功能需求(每條一個「使用者能…」+ 驗收句)

- **R1　PDF 轉結構化資料** 使用者（透過 PDF Parser CLI）能把 `top2025.pdf` 轉成結構化 JSON 單字庫。
  - 驗收：給定 已執行 `python -m src.pdf_parser`，當 解析完成，則 產出 `vocab.cleaned.json`（含 word/pos/zh_definition/source_page，去重，parse_confidence ≥ 0.85）。

- **R2　搜尋 / 篩選單字** 使用者能在 App 中依關鍵字、頁碼、頻率搜尋篩選單字清單。
  - 驗收：給定 已載入 `vocab.cleaned.json`，當 使用者輸入篩選條件，則 清單即時更新對應結果。

- **R3　勾選建立批次(≤25 字)** 使用者能勾選最多 25 個單字建立一個練習批次。
  - 驗收：給定 使用者瀏覽單字列表，當 已選滿 25 字，則 系統禁止再選並顯示提示。

- **R4　批次錄音播放** 使用者能對批次進行 TTS 批次播放（英文 → 間隔 → 中文 → 間隔 → 下一字），並可選 3/5/10 秒間隔。
  - 驗收：給定 已建立批次，當 使用者按下播放，則 依序播放並顯示進度條與目前單字高亮，斷網可用。

- **R5　翻牌卡學習** 使用者能透過翻牌卡學習單字（正面英文、背面中文 + 詞性）。
  - 驗收：給定 批次內有單字，當 使用者點擊卡片，則 顯示對應中文釋義與詞性。

- **R6　四題型練習 + 判分** 使用者能進行四種題型練習（中→英、英→中、拼字填空、聽音選字），並取得即時判分與結果頁。
  - 驗收：給定 使用者完成一題，當 提交答案，則 立即顯示對錯，錯題可加入重練。

- **R7　批次歷史與統計** 使用者能查看批次歷史列表（可重新進入）與統計（正確率 / 錯題分布），中斷可自動儲存並「繼續上次」。
  - 驗收：給定 使用者曾建立過批次，當 回到首頁，則 可見歷史列表與統計，並能從中斷處繼續。
  - ⚠️ 2026-07-06 調整：統計主體改由 R11(使用者成績與錯誤率)承接，本條保留批次歷史/續作部分，排入 M4。

### 2026-07-06 使用者回饋擴充（負責人已簽核）

- **R8　單字發音按鈕全面化** 使用者能在任何看得到單字的地方（列表、選字頁、翻牌卡、考試結果）按 🔊 聽該字發音。
  - 驗收：給定 畫面上顯示任一單字，當 使用者點該字旁的發音按鈕，則 以英文 TTS 唸出該字。

- **R9　雲端使用者帳號** 使用者能以 Google 帳號登入，成績與紀錄跨裝置（iPad / Android）同步。
  - 驗收：給定 使用者在 iPad 登入並完成一次考試，當 改用 Android 裝置以同帳號登入，則 可看到該次成績。

- **R10　選擇題考試（含聽力）** 使用者能設定頁數範圍與題數產生選擇題考卷：中→英、英→中交互出題，並含聽力題（播英文發音→選中文），聽力題可單獨成卷。
  - 驗收：給定 使用者選定頁數範圍與題數並開始考試，當 逐題作答完畢，則 顯示得分與逐題對錯；聽力題可重播發音。

- **R11　成績紀錄與累積錯誤率** 使用者能查看自己每次考試的成績歷史，以及每個單字的累積錯誤率（答錯次數/出題次數）。
  - 驗收：給定 使用者已完成多次考試，當 進入成績頁，則 可見依日期排列的成績列表與錯誤率排序的單字統計。

- **R12　錯題複習卷** 使用者能一鍵依累積錯誤率最高的單字自動產生一份複習考卷。
  - 驗收：給定 使用者錯誤率統計中有答錯過的字，當 按「錯題複習」，則 產生以高錯誤率單字優先的選擇題考卷。

## 「先不做」清單(明確排除，避免範圍蔓延)

- ~~不做帳號系統 / 雲端同步~~ → **2026-07-06 解除**：改做 Google 登入 + 雲端同步（R9，見 `DECISIONS.md`）。
- 不做匯出 MP3 到檔案系統。原因：非核心學習流程。
- 不做原生 App（iOS/Android）。原因：PWA 已可在 iPad Safari 與 Android Chrome 達成全部功能（含 TTS 語音）。
- 不做多語系。原因：僅服務正體中文使用者 + 英文單字。
- 不做自訂單字庫匯入。原因：範圍限定 `top2025.pdf` 來源詞庫。
- 不做雲端 TTS 音檔（neural voice）。原因：瀏覽器內建 TTS 零成本、可離線；音質若日後不滿意再評估。
