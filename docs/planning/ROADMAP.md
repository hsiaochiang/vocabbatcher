## 重大相依與風險

- 風險：R9 雲端帳號引入 Firebase 外部相依（需負責人建 Firebase 專案、設定 Google 登入），是專案首次接後端服務。
  → 緩解：選用免維護的 Firebase 免費額度方案；S2 切片 BRIEF 內附負責人設定步驟；PWA 其餘功能不依賴網路，斷網仍可學習。
- 風險：Web Speech API 在不同裝置音色/語音包不同（iPad vs Android），且 iPad 首次發音需使用者手勢觸發。
  → 緩解：所有發音一律由按鈕點擊觸發；驗收時在 iPad Safari 與 Android Chrome 實機各測一輪。
- 風險：專案原有 OpenSpec + GitHub Copilot 工作流與本套兩層流程過渡期並存，可能造成兩邊文件各自更新、不同步。
  → 緩解：`DECISIONS.md` 明確記錄過渡策略；`docs/roadmap.md`（舊）與本檔（新）在過渡期都保留，待舊流程淡出後再考慮整併或封存舊文件。
