## 目標（一句話）
> 學生登入 Google 帳號後，可依頁數範圍考選擇題與聽力題，成績與單字錯誤率雲端累積，並能一鍵產生錯題複習卷；所有單字旁都有發音按鈕。

## 技術選型（本階段新引入）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語音 | 瀏覽器內建 Web Speech API（沿用既有 `src/services/tts.ts`） | iPad Safari / Android Chrome 皆支援、離線可用、零成本；iPad 需點擊觸發 → 全部發音走按鈕 |
| 帳號 | Firebase Authentication（Google 登入） | 免自架伺服器、與靜態 PWA / GitHub Pages 相容 |
| 雲端資料 | Cloud Firestore（免費額度） | 成績/錯誤率文件型資料，離線快取內建（斷網先存本機、恢復自動同步） |
| 出題引擎 | 純前端演算法（從 `vocab.cleaned.json` 依 source_page 篩選＋隨機出題＋干擾選項） | 不需後端，斷網也能考（成績暫存，恢復網路再上傳） |

## 跨切片一致性（執行層務必遵守）

- **資料模型先講好（S2 定案後各切片共用）：**
  - `users/{uid}` — displayName、createdAt
  - `users/{uid}/examResults/{examId}` — 日期、模式、頁數範圍、題數、得分、逐題紀錄(word, 題型, 對錯)
  - `users/{uid}/wordStats/{word}` — attempts、wrong、wrongRate（由考試結果累加）
- **出題規則統一放 `src/services/exam.ts`**：S3 建立、S5 重用（僅換候選字池為高錯誤率優先）。
- **發音一律經 `src/services/tts.ts`**，不得散落 `new SpeechSynthesisUtterance`。
- 未登入時：學習功能（批次/翻牌/發音）照常可用；考試可考但提示「成績不會保存」，或要求先登入——S3 BRIEF 定案。

## 驗收軌道 B（負責人把關，白話清單）

1. S1：隨便開一頁，看到的每個單字旁都有喇叭，點了會唸。
2. S2：iPad 上用 Google 登入，Android 登同一帳號能看到同一個名字。
3. S3：選第 10~20 頁、10 題，考完看到分數；中英題型有交錯；聽力題會唸英文、選項是中文。
4. S4：考三次後，成績頁有三筆；統計頁看得到哪些字最常錯。
5. S5：按「錯題複習」，出來的卷子裡大多是剛剛錯過的字。
